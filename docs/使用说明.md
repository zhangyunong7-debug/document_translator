# 文档翻译工具 - 使用说明

## 简介

文档翻译工具是一款简洁高效的Windows桌面应用程序，专门用于将Word文档(.docx)和Excel文件(.xlsx)进行全文翻译。支持多种翻译引擎，包括免费的Google Translate和付费的Google/DeepL/百度翻译API。

## 功能特点

- **多格式支持**: 支持Word文档(.docx)和Excel文件(.xlsx)
- **批量处理**: 支持添加多个文件或整个文件夹
- **多引擎支持**:
  - Google Translate (免费，无需API密钥)
  - Google Translate API (需要API密钥)
  - DeepL API (需要API密钥)
  - 百度翻译 API (需要App ID和API密钥)
- **格式保留**: 自动保留原文的段落、表格、标题等格式
- **多语言**: 支持20+种语言的互译

## 安装步骤

### 方法一：使用预编译版本

1. 下载最新的 `DocumentTranslator.exe` 文件
2. 双击运行即可使用

### 方法二：从源码构建

1. 确保已安装Python 3.8或更高版本
2. 下载源码并解压
3. 双击运行 `build.bat`
4. 等待构建完成
5. 在 `dist/DocumentTranslator/` 目录下找到生成的exe文件

## 快速开始

### 1. 基本翻译流程

1. **启动程序**: 双击 `DocumentTranslator.exe`
2. **添加文件**: 点击"添加文件"按钮，选择要翻译的文档
3. **选择语言**:
   - 源语言：选择原文语言（或选择"自动检测"）
   - 目标语言：选择要翻译成的语言
4. **开始翻译**: 点击"开始翻译"按钮
5. **获取结果**: 翻译完成后，在输出目录中找到翻译后的文件

### 2. 使用免费翻译引擎（无需配置）

程序默认使用Google Translate免费引擎，无需任何API配置即可直接使用：

1. 在翻译设置中，选择"Google Translate (免费)"
2. 直接添加文件并开始翻译

### 3. 配置付费翻译API

如果您需要更高的翻译质量和更快的速度，可以配置付费API：

#### Google Translate API

1. 访问 [Google Cloud Console](https://console.cloud.google.com/)
2. 创建项目并启用 Cloud Translation API
3. 创建API密钥
4. 在程序中点击"配置API密钥"
5. 粘贴API密钥并保存

#### DeepL API

1. 访问 [DeepL API](https://www.deepl.com/pro-api)
2. 注册并订阅API服务
3. 复制API密钥
4. 在程序中点击"配置API密钥"
5. 粘贴API密钥并保存

#### 百度翻译 API

1. 访问 [百度翻译开放平台](https://fanyi-api.baidu.com/)
2. 注册开发者账号
3. 创建应用获取 App ID 和 API Key
4. 在程序中点击"配置API密钥"
5. 填写 App ID 和 API Key 并保存

## 详细功能说明

### 文件选择

- **添加文件**: 一次选择一个或多个文件
- **添加文件夹**: 批量添加文件夹中所有支持的文档
- **清除列表**: 移除所有已选择的文件
- **拖放支持**: 可以直接拖拽文件到程序窗口

### 翻译设置

- **翻译引擎选择**: 根据需求选择合适的翻译引擎
- **语言设置**: 支持20+种语言的自动检测和互译
- **输出目录**: 自定义翻译文件的保存位置

### 进度显示

- 实时显示翻译进度条
- 日志窗口显示详细的翻译状态
- 完成后显示成功/失败统计

## 支持的文件格式

### Word文档 (.docx)

支持的元素：
- 段落文本
- 表格内容
- 页眉页脚
- 标题和副标题

### Excel文件 (.xlsx)

支持的元素：
- 单元格文本内容
- 多个工作表
- 所有工作表内容

**注意**: 公式和数值不会被翻译，只会翻译文本内容

## 常见问题

### Q: 翻译失败怎么办？

A: 请检查以下几点：
1. 网络连接是否正常
2. API密钥是否配置正确
3. API配额是否用完
4. 尝试使用免费翻译引擎

### Q: 如何提高翻译速度？

A: 可以考虑：
1. 使用付费API（如DeepL）
2. 减少单次翻译的文件数量
3. 分割大文件为多个小文件

### Q: 翻译后的格式为什么会变化？

A: 程序会尽可能保留原文档的格式，但以下情况可能导致格式变化：
1. 某些特殊字体可能不可用
2. 复杂的表格结构
3. 图片和图表不会被翻译

### Q: 配置文件保存在哪里？

A: 配置文件保存在用户目录下的 `.translation_app/config.json`

## 技术支持

如遇到问题，请检查：
1. Python版本是否为3.8+
2. 依赖包是否完整安装
3. 网络连接是否正常

## 隐私说明

- 所有翻译请求直接发送到您选择的翻译服务提供商
- 程序不会收集或保存您的文档内容
- API密钥安全存储在本地配置文件中
